## Checklist de Entrega

Checklist operacional antes de apertar enviar. Se falhar em um item só, segure o envio. Entregável só é enviado uma vez, a primeira impressão cobra.

## Antes de abrir o documento

- [ ] Tenho a decisão-mãe escrita em uma frase.
- [ ] Sei quem vai ler (C-level, operação, time misto, fundador solo).
- [ ] Sei em que contexto vão ler (sozinhos, em reunião, no celular, impresso).
- [ ] Tenho todas as métricas coletadas com baseline e meta ao lado.
- [ ] Tenho todos os artefatos intermediários reunidos numa pasta só.

## Capa

- [ ] Título do projeto.
- [ ] Subtítulo com número-manchete (resultado principal).
- [ ] Nome do cliente e logo do cliente (se autorizado).
- [ ] Sua marca/assinatura.
- [ ] Data de entrega no formato pt-BR (ex: 23 de abril de 2026).
- [ ] Versão do documento (v1.0, v1.1 etc).

## Resumo executivo

- [ ] Cabe em 1 página.
- [ ] Segue estrutura SCQA (Situation, Complication, Question, Answer).
- [ ] Lista os 3 a 5 achados principais em bullets curtos.
- [ ] Destaca a recomendação central.
- [ ] Antecipa o próximo passo imediato.

## Contexto

- [ ] Objetivo do projeto explicitado.
- [ ] Escopo e duração declarados.
- [ ] Time envolvido listado.
- [ ] Premissas e limitações reconhecidas.
- [ ] Baseline do ponto de partida registrado.

## Método

- [ ] Descreve como você chegou nas conclusões.
- [ ] Lista fontes de dados.
- [ ] Declara metodologia de atribuição.
- [ ] Declara janelas temporais.
- [ ] Se houve limitação, está declarada com honestidade.

## Achados

- [ ] Cada achado começa com uma frase-conclusão.
- [ ] Cada achado tem ao menos uma métrica de suporte.
- [ ] Cada achado é acompanhado de gráfico ou visual.
- [ ] Achados estão priorizados por impacto, não por ordem cronológica.
- [ ] Estão entre 3 e 7 (acima disso perde força).

## Recomendações

- [ ] Cada recomendação aponta para um achado específico.
- [ ] Cada recomendação é verbo no infinitivo ("dobrar investimento em Reels de 15s").
- [ ] Recomendações estão ranqueadas por impacto vs. esforço.
- [ ] Matriz 2x2 (impacto/esforço) está incluída se houver 5+ recomendações.
- [ ] Cada recomendação tem estimativa de custo ou esforço.

## Próximos passos

- [ ] Lista de ações concretas.
- [ ] Cada ação tem responsável nomeado.
- [ ] Cada ação tem prazo.
- [ ] Ações estão em ordem de execução (o que faz segunda-feira, o que faz no mês 2).
- [ ] Existe algo para o cliente fazer nos primeiros 7 dias.

## Apêndices

- [ ] Dados brutos disponíveis em planilha separada (link no documento).
- [ ] Prints/screenshots de alta qualidade.
- [ ] Links para artefatos externos (pasta, Notion, Figma).
- [ ] Glossário se houver termos técnicos.
- [ ] Histórico de versões.

## Qualidade visual

- [ ] Tipografia: máximo 2 fontes.
- [ ] Paleta: máximo 3 cores.
- [ ] Margens generosas em todas as páginas.
- [ ] Nenhum gráfico está cortado, esmagado ou ilegível.
- [ ] Tamanho mínimo de fonte no corpo: 11pt.
- [ ] Títulos de gráfico são conclusões, não descrições.
- [ ] Imagens em alta resolução (nada abaixo de 150dpi para impressão).
- [ ] Footer com número de página.
- [ ] Consistência entre páginas (header, footer, espaçamento).

## Qualidade textual

- [ ] Revisão ortográfica pt-BR.
- [ ] Zero frases sem verbo.
- [ ] Zero parágrafos com mais de 5 linhas.
- [ ] Nada de jargão desnecessário ("sinergia", "alavancar", "top of mind" sem necessidade).
- [ ] Tom consistente do começo ao fim.
- [ ] Nome do cliente escrito igual em todas as páginas.
- [ ] Valores em R$ com formatação pt-BR (R$ 1.000,00, não R$ 1,000.00).
- [ ] Datas em pt-BR (23/04/2026 ou 23 de abril de 2026).

## Lógica e consistência

- [ ] Se o resumo executivo diz X, o corpo do documento prova X.
- [ ] Nenhum número aparece com duas versões diferentes em páginas diferentes.
- [ ] Gráfico X confirma recomendação Y.
- [ ] Não há contradição entre achados.
- [ ] Se há ressalvas, estão declaradas, não escondidas.

## Arquivo e entrega técnica

- [ ] Arquivo final exportado em PDF.
- [ ] PDF abre corretamente em iPhone, Android, Mac, Windows.
- [ ] Tamanho do PDF abaixo de 25MB (20MB ideal para WhatsApp).
- [ ] Nome do arquivo no padrão: "Entrega_[Cliente]_[Projeto]_[v1.0]_23abr26.pdf".
- [ ] Arquivo editável (Figma, Keynote, Docs) guardado em pasta interna.
- [ ] Backup em 2 locais diferentes.
- [ ] Link de compartilhamento testado antes de enviar.

## Mensagem de handoff

- [ ] Mensagem escrita antes do envio, não improvisada.
- [ ] Informa tempo estimado de leitura.
- [ ] Indica por onde começar (capa, resumo executivo, achados).
- [ ] Diz se haverá call síncrona ou é async.
- [ ] Abre espaço para perguntas.
- [ ] Define quando você espera resposta.

## Loom (opcional mas recomendado)

- [ ] Gravado com documento aberto do lado.
- [ ] Webcam ligada.
- [ ] Entre 3 e 10 minutos.
- [ ] Áudio limpo, sem ruído de fundo.
- [ ] Título informativo do vídeo.
- [ ] Link testado em aba anônima antes de enviar.

## Pós-entrega

- [ ] Agenda de follow-up marcada (7 a 15 dias depois).
- [ ] Template pronto para pedir feedback em 30 dias.
- [ ] Entregável salvo em portfólio interno (anonimizado se preciso).
- [ ] Lições do projeto documentadas em retro interno.
- [ ] Próxima proposta já pré-rascunhada se cliente for de longo prazo.

## Verificação final dos 3 segundos

Abra o PDF na capa. Em 3 segundos, alguém entende:

- [ ] De que projeto é?
- [ ] Quem é o cliente?
- [ ] Qual o resultado principal?

Se um desses não fica claro em 3 segundos, a capa precisa ser refeita.

## Verificação final dos 30 segundos

Abra o resumo executivo. Em 30 segundos, um CEO consegue:

- [ ] Entender o que foi feito?
- [ ] Entender o que funcionou?
- [ ] Saber o que fazer depois?

Se algum desses não está claro em 30 segundos, o resumo executivo precisa ser reescrito.

## Critérios de "pronto para enviar"

Só envie se os 5 itens abaixo forem verdade:

1. O cliente consegue ler só a página 1 e agir.
2. Toda métrica tem baseline e comparação.
3. Toda recomendação tem próximo passo com dono e prazo.
4. O arquivo é bonito aberto em qualquer dispositivo.
5. Você grava um Loom de 3 minutos e ele faz sentido.

Se um dos cinco falhar, não envie. Ajuste e retorne ao checklist.

## Frase pra lembrar

Entregar é comprometer reputação; checklist é proteção de reputação.
