## Formato de Apresentação

Escolher o formato errado destrói um entregável bom. Deck gigante vira doc ruim. Doc extenso vira deck pior. Este arquivo mostra quando usar cada formato e como estruturá-lo.

## Os 5 formatos principais

### 1. PDF denso

Quando usar:
- Consultoria estratégica, auditoria, relatório de resultado.
- Cliente C-level que imprime e lê com caneta na mão.
- Documento que vai viver na pasta do cliente como referência.
- Qualquer entrega que precisa passar bem em WhatsApp/email.

Tamanho: 10 a 40 páginas.

Estrutura:
1. Capa (1 página).
2. Índice com paginação (1 página).
3. Resumo executivo (1 página).
4. Contexto e método (1-2 páginas).
5. Achados (3-10 páginas).
6. Recomendações (2-4 páginas).
7. Próximos passos (1 página).
8. Apêndices (sem limite).

Ferramentas:
- Figma para diagramação premium.
- Keynote exportado como PDF.
- Pitch.com.
- Canva para algo mais rápido.
- Notion exportado com cuidado (geralmente o resultado é pobre).

Observações:
- Sempre 4:3 ou A4 retrato; A4 é padrão para cliente BR.
- Footer com número da página e nome do projeto.
- Header discreto com logo do cliente na direita.

### 2. Notion compartilhado

Quando usar:
- Time do cliente vai operacionalizar o que você entregou.
- Entregável precisa ser vivo (atualizado depois da entrega).
- Você precisa entregar templates replicáveis (de post, de email, de funil).
- Cliente já usa Notion como base de conhecimento.

Estrutura:
1. Página-mãe com o resumo e índice clicável.
2. Subpáginas por tema (uma por achado grande).
3. Databases para templates replicáveis.
4. Toggle para apêndices pesados (não ocupam espaço).

Boas práticas:
- Use cover image consistente com a marca.
- Toggle para detalhes, cabeçalho limpo.
- Callouts para alertas e insights.
- Sempre deixe uma página "Como usar este Notion" no topo.
- Permissões: cliente como editor na sua pasta, nunca na database-mãe.

Observações:
- Exporte como PDF uma cópia congelada (versão 1.0) como backup.
- Notion fica feio em mobile; se cliente consome no celular, PDF é melhor.

### 3. Deck (Keynote, Pitch, Figma Slides)

Quando usar:
- Apresentação síncrona ao vivo (call ou presencial).
- Pitch de estratégia para aprovação.
- Resultado de campanha/lançamento com alta carga visual.
- Board meeting ou apresentação para múltiplos stakeholders.

Tamanho: 15 a 40 slides. Acima disso é doc disfarçado de deck.

Estrutura:
1. Capa (1 slide).
2. Agenda (1 slide).
3. Contexto em 3-5 slides.
4. Achados (1 slide por achado).
5. Recomendação síntese (1 slide).
6. Próximos passos (1 slide).
7. Obrigado/contato.

Ferramentas:
- Keynote: melhor acabamento visual, Mac-only.
- Pitch.com: colaborativo, templates fortes, exportação boa.
- Figma Slides: bom pra quem já trabalha em Figma.
- Google Slides: funcional, feio por padrão, evite para cliente premium.
- PowerPoint: corporativo BR; acompanhe com tema customizado.

Regras visuais:
- 1 ideia por slide.
- Título do slide é uma frase completa com conclusão ("Reels de 15s converteram 3x mais"), não um rótulo ("Reels curtos").
- Gráfico ocupa 70% do espaço quando é a estrela.
- Fundo claro em dia, escuro para mood.
- Fonte mínima 18pt; títulos 36pt+.

### 4. Loom (vídeo walkthrough)

Quando usar:
- Handoff async: cliente assiste quando puder.
- Explicar um documento denso em 5 minutos.
- Apresentar um protótipo/funil/peça criativa.
- Substituir uma call de atualização.

Tamanho: 3 a 10 minutos. Acima disso, edite ou parta em mais de um vídeo.

Estrutura:
1. Oi rápido (10 seg) com nome do projeto.
2. O que você vai mostrar (20 seg).
3. Walkthrough do documento ou tela (60-70% do tempo).
4. Recomendação/próximo passo (20% do tempo).
5. Call-to-action final (o que o cliente faz depois de assistir).

Boas práticas:
- Webcam sempre ligada (mesmo que pequena no canto).
- Gravar com o documento aberto do lado, não em outra aba.
- Iluminação decente, áudio limpo.
- Título do Loom vira o subject do email ("Entrega Marca Luana, 7 min walkthrough").
- Transcrição automática sempre ligada.

Ferramentas:
- Loom (padrão).
- Tella.tv (mais visual).
- ScreenStudio (macOS, visual premium).
- Riverside para vídeo mais formal.

### 5. Google Docs

Quando usar:
- Entregável que o cliente vai editar junto.
- Documento legal/comercial (contrato, proposta, briefing revisado).
- Processo em andamento onde você precisa de comentários inline.
- Nota técnica curta (1-4 páginas).

Estrutura:
- Cabeçalho com título, data, autor, versão.
- Índice automático (Inserir > Sumário).
- Seções com headings consistentes (H1, H2, H3).
- Comentários resolvidos antes de congelar.

Boas práticas:
- Configure permissão cuidadosamente: "Comentar" para cliente na maioria dos casos, não "Editar".
- Versão final: exporte PDF, guarde como v1.0.
- Use fonte limpa (Inter, Roboto, Georgia para texto longo).
- Margens generosas, espaçamento 1.5.

Quando NÃO usar Google Docs:
- Entregável com muito dado visual (vire PDF/deck).
- Cliente C-level que aprecia forma (vire PDF).
- Entregável para compartilhar em grupo (vire PDF/Notion).

## Matriz de decisão rápida

| Situação | Formato primário | Formato secundário |
|---|---|---|
| Relatório de consultoria premium | PDF denso | Deck para pitch |
| Auditoria | PDF denso | Planilha de apêndice |
| Estratégia de conteúdo | PDF + Notion | Loom walkthrough |
| Lançamento/campanha | Deck | PDF de resultado |
| Handoff operacional | Notion | Loom |
| Nota técnica curta | Google Docs |, |
| Entrega rápida (48h) | Loom + PDF simples |, |
| Apresentação board | Deck | PDF backup |
| Projeto de marca | PDF + pasta com fontes | Loom |
| Sprint de produto | Notion | Loom |

## Combinando formatos

Entregáveis premium quase nunca são só um formato. Combine:

- Combo clássico: PDF denso (referência) + Loom de 5 min (contexto) + call de 30 min (dúvidas).
- Combo operacional: Notion (vivo) + PDF congelado (backup) + Loom.
- Combo board: Deck (apresentação) + PDF (backup para quem não viu) + sumário de 1 página.

## Padrões visuais por formato

Cada formato pede um ritmo visual. Não copie o mesmo layout.

- PDF: respiro máximo, tipografia protagonista, grid rígido.
- Deck: contraste alto, 1 ideia por slide, imagem grande.
- Notion: ícones coloridos, emojis como marcador (ok aqui), toggle para densidade.
- Loom: você é o elemento visual principal, documento em fundo.
- Docs: tipografia serifada para leitura longa, hierarquia de heading limpa.

## Adaptações para cliente brasileiro

- A maioria dos clientes BR ainda imprime entregável importante. Pense em impressão P&B.
- WhatsApp é canal de envio real. Arquivo não pode passar de 100MB; idealmente 20MB.
- Cliente BR de negócio tradicional prefere PDF em A4 a 16:9.
- Cliente BR de tech/startup aceita Notion e Figma bem.
- Cliente BR de creator/influenciador pede Loom + PDF porque consome muito mobile.

## Erros comuns de formato

- Deck de 80 slides virando documento de referência.
- PDF de 5 páginas com fonte 10pt e margens mínimas (parece apertado).
- Google Docs colado inteiro no email do cliente (fica gigante).
- Notion com 14 níveis de subpágina (cliente perde no quarto clique).
- Loom de 25 minutos (ninguém assiste).

## Frase pra lembrar

Formato é embalagem; o entregável só funciona quando a embalagem cabe no bolso da decisão.
