# Referências de Design por Estilo

Catálogo de DESIGN.md prontos para agentes de código, agrupados por estilo visual e contexto de uso. Cada um é um manual completo com tokens de cor, tipografia, espaçamento e racional de design.

Fonte: designdotmd.directory (projeto de @bidah).

**Como usar:** ao escolher uma referência, acesse `https://designdotmd.directory/<slug>` e copie o DESIGN.md para o repositório do projeto. O slug é o nome entre parênteses de cada linha.

## Como escolher uma referência

1. **Identifique o contexto** (categoria do produto).
2. **Escolha 2 candidatos** dentro da categoria.
3. **Veja os tokens de ambos** em `https://designdotmd.directory/<slug>`.
4. **Pergunte ao usuário qual das duas** prefere. Não decida sozinho em projetos com marca estabelecida.
5. **Baixe o DESIGN.md** escolhido e coloque na raiz do projeto para Claude Code ler em futuras conversas.

## Como combinar referências

- **Produto principal:** escolha 1 estilo âncora.
- **Landing page:** pode ter estilo mais editorial/forte que o app.
- **Documentação:** pode ser mais sóbria que o produto.
- **Nunca misture 3+ estilos** no mesmo produto.
