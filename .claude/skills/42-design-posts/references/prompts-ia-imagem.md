# Prompts de IA para gerar fundos

Prompts prontos pra produzir o fundo fotográfico de cada peça. Use Nano Banana (Gemini), Midjourney 6+ ou Flux 1.1 Pro. Não precisa fotografar nada manualmente.

## Estrutura mestre do prompt

Todo prompt segue mesma fórmula:

```
[ASSUNTO] photographic background, [PALETA], [LUZ], [SOMBRA PROTAGONISTA],
[AMBIENTE], [COMPOSIÇÃO E ESPAÇO NEGATIVO], [ESTILO TÉCNICO],
no text, no people faces, vertical 4:5 aspect ratio
```

7 blocos. Trocar conteúdo de cada bloco mantendo a estrutura.

## Por ferramenta

### Nano Banana (Gemini Image)

- Cole o prompt direto.
- Aspecto: especifique "vertical 4:5" no fim.
- Variação: gera 4 opções por padrão. Escolhe a melhor.
- Vantagem: gratuito, rápido, ótimo pra mood realistic.

### Midjourney v6+

- Cole o prompt + parâmetros: ` --ar 4:5 --style raw --v 6.1`.
- `--style raw` evita estilo "pintura digital".
- Use `--no text, faces, people` pra reforçar.
- Vantagem: melhor controle de luz e composição.

### Flux 1.1 Pro

- Cole o prompt limpo (não precisa de parâmetros especiais).
- Aspect ratio: configure no painel para 4:5 (832x1080 ou 896x1152).
- Vantagem: realismo fotográfico extremo, ótimo pra detalhes de textura.

## Truques que aumentam qualidade

1. **Especifique filme analógico** ("Kodak Portra 400", "Fuji Pro 400H"). IA entende e dá tom certo.
2. **"Shallow depth of field"** sempre. Cria profundidade real.
3. **"No text, no people faces"** sempre. Evita problema de mãos disformes e texto inventado.
4. **"Generous negative space"** + área específica ("in upper third"). Garante área pro texto.
5. **"Subtle film grain"**. Quebra a sensação de IA gerada digitalmente.
6. **"Vertical 4:5"** ou `--ar 4:5`. Formato Instagram feed.

## Quando o resultado não vier bom

Problema 1: rosto humano apareceu (não queria).

- Adicione "no people, no faces, no humans" no fim.
- Use silhueta ou sombra apenas: "silhouette shadow of human hand only".

Problema 2: texto inventado apareceu.

- Adicione "no text, no letters, no writing, no signs" no fim.
- Reforce: "completely empty wall surface with only shadow".

Problema 3: cor saiu errada (muito saturada ou neon).

- Adicione: "muted desaturated tones, vintage color grading, low saturation".
- Especifique filme analógico.

Problema 4: composição cheia demais (sem espaço pro texto).

- Reforce: "large empty area in [posição], generous negative space, minimalist composition".

Problema 5: realismo baixo (parece ilustração).

- Adicione: "photorealistic, real photograph, DSLR camera, 50mm lens".

## Custo aproximado por peça

- Nano Banana: gratuito (uso normal).
- Midjourney: ~US$ 0.05-0.10 por geração (plano Standard).
- Flux 1.1 Pro: ~US$ 0.04-0.06 por geração (Replicate).

Para 30 posts/mês, custo de IA fica entre US$ 0 e US$ 5.

## Frase pra lembrar

Prompt bom não é prompt longo. É prompt específico nos 5 elementos críticos: paleta, luz, sombra, espaço negativo, estilo técnico. Teste, ajusta, repete. Em 3-5 gerações vem o resultado certo.
