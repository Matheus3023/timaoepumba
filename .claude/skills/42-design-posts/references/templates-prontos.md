# 8 templates prontos

Cada template baseado em uma das 9 referências analisadas. Use como esqueleto pronto. Trocar texto + fundo, manter estrutura.

## Template 01: Versículo Serif (acolhedor)

Base: peça "Não é sobre o que você viveu / 2 Coríntios 5:17" com flores reais.

```
Canvas: 1080x1350
Preset paleta: A (Bege Tan)
Combo tipografia: A (Serif Clássica)
Composição: Padrão A (centro)

ESTRUTURA:
[Y=0-110px]    Zona segura superior
[Y=110-540px]  Foto/sombra dominante (objeto físico no canto inferior direito)
[Y=540-700px]  Título serif 40-48pt centralizado, 2 linhas
                "Frase reflexiva curta.
                 Frase de continuidade."
[Y=700-720px]  Espaço respiro
[Y=720-820px]  Subtítulo bold sans 18pt
                "Frase de apoio em 1 linha bold."
[Y=820-840px]  Espaço respiro
[Y=840-960px]  Texto regular sans 16-18pt
                "Texto bíblico ou contextual em 2-3 linhas."
[Y=960-980px]  Espaço respiro
[Y=980-1020px] Citação sans bold 16pt
                "Referência bíblica"
[Y=1240-1280px] Handle centralizado
```

Quando usar: versículo + reflexão devocional pessoal. Ideal pra acolhimento.

## Como duplicar no Figma

1. Crie um arquivo "BRAND - Posts Estaticos" no Figma.
2. Em cada Frame separado de 1080x1350, monte 1 dos 8 templates.
3. Salve cada um como Component (`Cmd+Alt+K`).
4. Pra peça nova, duplica o Component, troca texto + fundo.
5. Mantém os mesmos color styles, text styles e effects.

Total de tempo pra montar todos: 4-6h primeira vez. Depois cada peça nova fica em 15-25 min.

## Como duplicar no Canva

1. Crie um Design "BRAND Posts Instagram 1080x1350".
2. Pra cada template acima, crie 1 página dentro do mesmo Design.
3. Salve como "Modelo da equipe" se tiver Canva Pro.
4. Pra peça nova, "Duplicar página" + trocar conteúdo.

## Como aplicar essas estruturas

A skill vai gerar pra você um briefing tipo:

```
TEMPLATE: 02 (Afirmação Sans Bold)
PALETA: Preset A (Bege Tan)
TIPOGRAFIA: Combo B (Sans Moderna)
TEXTO PRINCIPAL: "[texto que você passou]"
PALAVRAS BOLD: [palavras escolhidas]
HANDLE POSIÇÃO: topo
PROMPT IA FUNDO: [prompt detalhado]
SPECS FIGMA: [coordenadas exatas dos blocos]
```

Você cola esse briefing no Figma/Canva e executa em 20 min.

## Frase pra lembrar

Template não é prisão, é trampolim. A primeira peça você executa o template inteiro. A décima você adapta com confiança. A centésima você cria o seu próprio template e adiciona aqui.
