# Índice, O que cada Agent e Skill faz

## Os 14 Agents

| Agent | Função |
|-------|--------|
| **closer** | Fechamento de novos clientes: discovery call, precificação de fee (BDI/margem), proposta comercial completa com ROI e pitch deck. |
| **comercial** | Auditoria semanal de time comercial: analisa conversas de WhatsApp/CRM com rubric de 4 dimensões (SLA, abordagem, qualificação, objeção) e devolve relatório. |
| **copywriter** | Copy de aquisição e conversão: anúncios Meta, copy de landing page, roteiro de VSL. Sempre múltiplas variações testáveis (mín. 3 ganchos). |
| **corona** | Social media completo (Método Corona de 4 fases): análise de referência, planejamento mensal, post avulso e grade estratégica HHH (HERO/HUB/HELP). |
| **designer** | Entregas visuais: carrossel, PDF/deck paginado print-ready (3 modelos canônicos), landing page, mockup, briefing visual e prompt pra IA de imagem. |
| **diretor-operacoes** | Processos e SOPs (Método DOP de 4 fases): mapeia, desenha (RACI/SLA), documenta em formato didático e implanta. |
| **financeiro** | Gestão financeira de agência: contrato, BDI/overhead, rentabilidade por projeto, cobrança recorrente, régua de inadimplência e forecast de MRR. |
| **gerente-de-contas** | Retenção e crescimento de clientes: onboarding 30-60-90, cadência de relacionamento, health score anti-churn e upsell/cross-sell. |
| **orquestrador** | Coordena vários agents num briefing: quebra em tarefas, cria no gestor de projetos, dispara especialistas em paralelo e consolida o pacote. |
| **prospeccao** | Topo de funil B2B: ICP + anti-ICP, lista de leads, cadência multi-canal, cold email 2.0, sequência de 5-9 toques e meta semanal. |
| **publisher** | Publicação de conteúdo no Instagram: valida pacote pronto, sobe como rascunho/agendado e publica só após aprovação humana (feed/carrossel/Reels). |
| **setup-tracking** | Rastreamento de marketing: Meta Pixel + CAPI deduplicado, GA4, GTM server-side, Consent Mode v2 + LGPD, UTM e QA de tracking. |
| **trafego** | Meta Ads de ponta a ponta: estratégia visando MQL, estrutura CBO/ABO, modelagem de ROI/cohort, subida de campanha (sempre em PAUSED) e reporting. |
| **web-designer** | Produtiza e publica a landing page: responsivo, Web Vitals, SEO + Open Graph, repositório GitHub e deploy Vercel com domínio custom. |

> Os agents se conversam: o `orquestrador` coordena `corona`, `copywriter`, `trafego` e
> `designer`; o `designer` desenha e o `web-designer` põe no ar; o `setup-tracking`
> entrega sinal limpo pro `trafego`. Você pode usar cada um sozinho ou em conjunto.
